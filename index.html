極巨化 / 超極巨化搜尋

在 twpkinfo 道館地圖上，用文字搜尋寶可夢的極巨化點，並依你的位置由近到遠排序。手機、電腦都能用。

1. 複製書籤程式碼

電腦版也可以直接把這個按鈕拖到書籤列：極巨化搜尋

2. 建立書籤

  1. 在這個頁面點右上角「⋮」→ 點「☆」把它加入書籤
  2. 再點「⋮」→「書籤」，找到剛剛那個書籤，長按 →「編輯」
  3. 名稱改成 dmx（短一點比較好打）
  4. 網址整個刪掉，貼上剛剛複製的程式碼，儲存
  1. 在這個頁面點下方的「分享」按鈕 →「加入書籤」→ 儲存
  2. 點下方的「書籤」圖示（打開的書本），點「編輯」
  3. 點剛剛那個書籤，名稱改成 極巨化搜尋
  4. 網址整個刪掉，貼上剛剛複製的程式碼，按「完成」

3. 使用

  1. 打開 twpkinfo 道館地圖
  2. Android：點網址列，輸入 dmx，在下拉選單裡點那個書籤（有星號圖示的那一列，不是搜尋建議）
    iPhone：點「書籤」圖示 → 點「極巨化搜尋」
  3. 畫面下方會出現搜尋面板。先拖動一下地圖，讓它收集資料
  4. 輸入或點選寶可夢，第一次會詢問位置權限，請按「允許」，結果就會依距離排序
  5. 點「在地圖上顯示」會跳到那個位置，面板也會自動收合；點「＋」可以展開回來

星級表每天從 Snack Nap 自動更新，工具功能更新時也不用重新設定書籤。這個工具只會讀取網頁自己已經載入的資料，不會另外向 twpkinfo 發出請求。
