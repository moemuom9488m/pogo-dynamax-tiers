# pogo-dynamax-tiers

Pokémon GO 團體戰 / 極巨化搜尋書籤工具（安裝頁：https://moemuom9488m.github.io/pogo-dynamax-tiers/），以及極巨化 / 超極巨化團體戰的星級表，每天由 GitHub Actions 從 [Snack Nap](https://www.snacknap.com/max-battles) 自動抓取。

`tiers.json` 格式：`{ "D": { 圖鑑編號: 星級 }, "G": { 圖鑑編號: 星級 }, "updated": "YYYY-MM-DD" }`，其中 `D` 是極巨化、`G` 是超極巨化。
